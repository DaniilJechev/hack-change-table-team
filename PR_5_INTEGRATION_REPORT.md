## Доработка Эмиля после слияния

В PR №4 добавлены IdentityClient и Telegram handlers: приватный /start с кодом,
повторный вход, профиль с ролью из backend, русские безопасные ответы без LLM.
Код и ключ не передаются в пользовательский ответ; тело серверной ошибки игнорируется.
Запрос имеет общий лимит 5 секунд и не следует редиректам. Группы и сообщения без
подтверждённого пользователя не обращаются к backend.

Согласованы три различия между нашей подготовкой и готовым runtime:
1. Алиасы переменных MCP_ATLASSIAN_URL и MCP_CALENDAR_URL + приоритет окружения.
2. Jira Basic auth из JIRA_USERNAME/JIRA_API_TOKEN; секреты защищены при записи фикстур.
3. Автовыбор встроенного read-only GitHub wrapper в контейнере агента.

Код Go, схема БД и серверы MCP после merge не менялись. В CI добавлены только запуск
нашей сквозной приёмки на отдельном проекте и сохранение официальных каталогов.
Спецификация привязки внесена через stage-1-bot-binding и после приёмки архивирована; обновлены foundation и telegram-identity.
