# agent-foundation Specification

## Purpose
Части Эмиля и Даниила Этапа 2: безопасный Router, границы Executors, изолированный synthetic-демо и воспроизводимая оценка маршрутизации.

## Requirements

### Requirement: ST2-ROUTE-1 Безопасный Router
Router MUST валидировать JSON по закрытой схеме RT-01 без confidence-порогов, отклонять лишние поля и параметры user_id/team_id/role. Неизвестный кейс SHALL становиться out_of_scope; невалидный JSON, ошибка или таймаут LLM до 20 секунд SHALL включать правила. Команды MUST обрабатываться правилами без LLM. Вход ограничен 4000 символами, параметры не предоставляют полномочия.

#### Scenario: Валидная модель
- **WHEN** LLM вернула допустимый case и параметры
- **THEN** запускается именно этот Executor без порога уверенности

#### Scenario: Ошибка модели
- **WHEN** JSON невалиден, содержит дополнительные поля или LLM недоступна
- **THEN** используются правила без раскрытия ответа модели

#### Scenario: Уточнение
- **WHEN** фраза неоднозначна, включая «Нужен доступ к Олегу»
- **THEN** возвращается clarify с вариантами инструмента и контакта

### Requirement: ST2-EXEC-1 Граница каркаса
Реестр MUST содержать все кейсы RT-01 и прямые brief_render/access_events; unknown SHALL исполнять out_of_scope. Контекст роли и команды MUST поступать из доверенного профиля или явно включённого публичного synthetic-демо. interns_status MUST быть запрещён стажёру. Каркас MUST честно сообщать о ещё не подключённых бизнес-функциях. Ссылки SHALL подставляться только кодом по известным citation source_id; невалидный JSON или выдуманная ссылка MUST заменяться шаблоном.

#### Scenario: Прямой триггер
- **WHEN** запускается кнопка или brief_render/access_events
- **THEN** Executor вызывается без Router

#### Scenario: Запрет и бюджет
- **WHEN** запрошен инструмент вне кейса или четвёртый вызов
- **THEN** gateway не вызывается, отказ фиксируется без аргументов и секретов

#### Scenario: Невалидный ответ
- **WHEN** ответ Executor нарушает схему или ссылается на неизвестный source_id
- **THEN** возвращается безопасный шаблон без выдуманного факта

#### Scenario: Роль стажёра
- **WHEN** стажёр запускает interns_status текстом или кнопкой
- **THEN** сведения о стажёрах не запрашиваются

### Requirement: ST2-DEMO-1 Изолированные шаги
DEMO_MODE=true SHALL разрешать явное /demo для публичного синтетического профиля; этот режим не создаёт реальную привязку. /demo next SHALL менять шаг только своей сессии, не зацикливать последний шаг; reset SHALL возвращать первый, off SHALL отключать демо. Отсутствующая фикстура MUST давать статус нет данных без сети. Состояние SHALL быть ограничено по памяти и сбрасываться после перезапуска. В live-режиме /demo MUST быть запрещён.

#### Scenario: Следующий шаг
- **WHEN** один пользователь отправляет /demo next
- **THEN** его replay использует step_2, а другой остаётся на step_1

#### Scenario: Конец и сброс
- **WHEN** достигнут последний шаг, затем отправлен reset или off
- **THEN** шаг не зацикливается, reset возвращает первый шаг, off убирает synthetic-контекст

#### Scenario: Групповой чат
- **WHEN** /demo или запрос приходят из группы либо без подтверждённого пользователя
- **THEN** профиль, Router и данные не запрашиваются, бот предлагает личный чат

### Requirement: ST2-DATA-1 Данные и оценка
Карточка команды и каталог MUST иметь Pydantic-схемы, роли/владельцев/ссылки и synthetic-метку. Набор Router SHALL содержать 70 фраз с покрытием всех 16 кейсов и отдельный контрольный набор. Оценка MUST выводить accuracy, ошибки параметров и confusion matrix, различать rules и явно включённую LLM. Прогон rules MUST работать без сети.

#### Scenario: Контракты seed
- **WHEN** данные не содержат обязательной роли, имеют чужую команду или неверного владельца
- **THEN** проверка отклоняет данные

#### Scenario: Оценка Router
- **WHEN** запущен offline eval
- **THEN** получен воспроизводимый отчёт для всех кейсов без внешней LLM
