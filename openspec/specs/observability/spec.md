# observability Specification

## Purpose
Наблюдаемость MVP: агрегатные метрики H0–H3 для Grafana без персональных данных, журнал вызовов MCP
без аргументов и ответов, схема `rag_chunks` для векторного поиска H3 в миграциях backend.

## Requirements

### Requirement: ST4-METRICS-1 Метрики без персональных данных
Backend SHALL сохранять признак h2/h3 у нового вопроса и метаданные MCP case/server/tool/outcome с серверным временем и пользователем из авторизации. Журнал MUST NOT принимать аргументы и ответы инструментов. Grafana SHALL читать только агрегаты через отдельную PostgreSQL роль без доступа к исходным таблицам. Учетная запись просмотра Grafana SHALL иметь роль Viewer. Отсутствующая выборка доли MUST давать NULL, а не выдуманный результат.

#### Scenario: Оценки и доступ
- **WHEN** пользователь меняет оценку ответа и ошибочная проверка доступа предшествует успешной
- **THEN** учитывается последняя оценка отдельно для h2/h3 и время до первого granted без ошибки после requested_at

#### Scenario: Отклонённый вызов
- **WHEN** политика агента отклоняет инструмент записи
- **THEN** журнал сохраняет отклонение отдельно от выполненного вызова и не хранит его аргументы

### Requirement: ST4-RAG-1 Схема в миграциях
Backend SHALL создавать совместимую с агентом таблицу rag_chunks с vector(384), соответствующую multilingual-e5-small. Миграция MUST сохранять существующие чанки. Индексация SHALL записывать чанки, не создавая схему. Режим bm25 MUST NOT обращаться к таблице.

#### Scenario: Существующий индекс
- **WHEN** миграция выполняется поверх созданной ранее агентом таблицы
- **THEN** строки остаются доступны и повторная миграция не создаёт дублей
