# foundation Specification

## Purpose
Проверяемый каркас Этапа 0: запуск инфраструктуры, безопасные команды Telegram, env-конфигурация, контракты данных и CI. Не заменяет спецификации следующих этапов H0–H3.

## Requirements

### Requirement: ST0-INFRA-1 Запуск каркаса
Каркас SHALL запускать PostgreSQL 16 с pgvector, Redis 7, Grafana, backend и agent одной командой `make up`; каждый сервис MUST иметь healthcheck. Backend MUST отдавать JSON на GET /health и завершаться по SIGTERM.

#### Scenario: Запуск
- **WHEN** запускается `make up` с Docker Engine
- **THEN** пять сервисов становятся healthy, /health backend возвращает status=ok

#### Scenario: Некорректный HTTP-запрос
- **WHEN** клиент запрашивает неизвестный URL или POST /health
- **THEN** backend возвращает 404 или 405 соответственно

### Requirement: ST0-BOT-1 Безопасное приветствие
Бот SHALL отвечать на /start и /help на русском без LLM. Без настроенного backend SHALL работать автономный каркас без привязки; при настроенном backend MUST использовать контракт ST1-BIND-1. H0–H3 остаются недоступны.

#### Scenario: Команда start
- **WHEN** backend не настроен и пользователь отправляет /start, в том числе с кодом
- **THEN** бот показывает меню каркаса без привязки и без данных команды

#### Scenario: Команда help
- **WHEN** пользователь отправляет /help
- **THEN** бот показывает возможности текущего этапа и ограничения

### Requirement: ST0-CONFIG-1 Конфигурация и LLM
Каркас MUST читать конфигурацию из env, скрывать секреты в repr, проверять обязательные параметры live-режима и использовать фейковую LLM в демо. LLM-клиент SHALL поддерживать OpenRouter и совместимый chat-completions API по LLM_BASE_URL без изменения кода. При ошибке, пустом ответе или таймауте не более 20 секунд MUST возвращаться переданный шаблон без раскрытия ошибки пользователю.

#### Scenario: Демо без ключа
- **WHEN** DEMO_MODE=true и нет ключей внешних сервисов
- **THEN** fake LLM и offline smoke работают без сети

#### Scenario: Live без обязательных настроек
- **WHEN** DEMO_MODE=false и не задан токен бота или параметры LLM
- **THEN** запуск завершается с понятным сообщением без значений секретов

#### Scenario: Смена провайдера
- **WHEN** задаются новый LLM_PROVIDER, LLM_MODEL и LLM_BASE_URL
- **THEN** клиент отправляет запрос к указанному API с заданной моделью

#### Scenario: Отказ LLM
- **WHEN** LLM возвращает ошибку, пустой ответ или превышает таймаут
- **THEN** возвращается шаблонный текст

### Requirement: ST0-SCHEMA-1 Контракты данных
Pydantic-схемы SHALL проверять роль пользователя, закрытый список кейсов Router и result/citations Executor; лишние поля MUST отклоняться.

#### Scenario: Неверный контракт
- **WHEN** передана неизвестная роль, кейс или лишнее поле
- **THEN** валидация отклоняет объект

### Requirement: ST0-QA-1 Проверка каркаса
CI SHALL запускать Go и Python тесты без реальной LLM, проверять покрытие строго выше 80% отдельно, валидировать OpenSpec и проверять контейнерный запуск. Репозиторий MUST содержать синтетический seed и анкету без выдуманных результатов.

#### Scenario: Проверка изменения
- **WHEN** открывается PR или обновляется main
- **THEN** CI проверяет тесты, покрытие, спецификации и Compose smoke
