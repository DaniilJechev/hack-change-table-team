# Персональные изменения Jira в H0

Собирать историю статуса, исполнителя, срока, приоритета и описания из read-only
Jira MCP v0.24.1. Сохраняется согласованный период с прошлого успешного брифа
(первый запуск — сутки, в понедельник три дня), персональный охват и ссылки.
Демо продолжает использовать существующие фикстуры без дополнительных вызовов.
Новые инструменты и внешние записи не добавляются.
