## ADDED Requirements

### Requirement: FR-H0-12 Уточнения по брифу
После брифа агент SHALL сохранять в памяти отобранные пункты (`item_id`, источник, сущности) и разрешать уточнения по ним из памяти: «подробнее про 2-й пункт», «что с PR #45?», «а по календарю?». Пункт MUST выбираться кодом по номеру, сущности или источнику; URL MUST подставляться кодом по `item_id`, LLM MUST NOT формировать ссылки. Если пункт не найден в памяти, бот SHALL отвечать по обычному правилу FR-H0-07. Уточнение, в котором названы номер PR или ключ задачи Jira (например, `ORD-121`), присутствующие в последнем брифе в окне памяти, SHALL разрешаться по пунктам этого брифа, даже если между брифом и уточнением были другие ходы. Короткое сообщение, называющее ровно один источник («что там по Jira напомни»), SHALL разрешаться по пунктам этого источника из сохранённого брифа без повторного сбора; если пунктов этого источника в сохранённом брифе нет, бот SHALL выполнять обычный бриф по этому источнику (FR-H0-07).

#### Scenario: Подробнее про пункт
- **WHEN** после брифа стажёр пишет «подробнее про 2-й пункт»
- **THEN** бот показывает второй пункт брифа со ссылкой, подставленной кодом по его `item_id`

#### Scenario: Вопрос про PR из брифа
- **WHEN** в последнем брифе есть пункт о PR #45, и стажёр пишет «что с PR #45?»
- **THEN** бот отвечает по этому пункту со ссылкой на PR #45

#### Scenario: Другой источник
- **WHEN** после брифа по Git стажёр пишет «а по календарю?»
- **THEN** бот отвечает только пунктами Google Calendar

#### Scenario: Пункта нет
- **WHEN** стажёр пишет «подробнее про 9-й пункт», а в брифе 5 пунктов
- **THEN** бот сообщает, что такого пункта нет, и не показывает ссылок

#### Scenario: PR после других вопросов
- **WHEN** в окне памяти есть бриф с пунктом о PR #45, после брифа стажёр задал другие вопросы и затем пишет «что с PR #45?»
- **THEN** бот отвечает по этому пункту брифа со ссылкой на PR #45, подставленной кодом

#### Scenario: Задача из брифа
- **WHEN** в последнем брифе в окне памяти есть пункт о задаче ORD-121, и стажёр пишет «что с ORD-121?»
- **THEN** бот отвечает по пункту об ORD-121 со ссылкой на задачу, подставленной кодом

#### Scenario: Источник из сохранённого брифа
- **WHEN** в окне памяти есть бриф с пунктами Jira, и стажёр пишет короткое сообщение, называющее ровно один источник, например «что там по Jira напомни»
- **THEN** бот показывает только пункты Jira из сохранённого брифа со ссылками, подставленными кодом, без повторного сбора брифа; если в сохранённом брифе нет пунктов этого источника, бот выполняет обычный бриф по этому источнику (FR-H0-07)
