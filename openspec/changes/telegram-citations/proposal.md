# Ссылки-сноски в Telegram

## Why
Ссылки на источники сейчас идут блоком «Источники:» в конце сообщения голыми URL (`reports/TASK_GUARD_TELEGRAM_CITATIONS.md`): стажёр не видит, какой пункт какой ссылкой подтверждён, а длинный список URL засоряет ответ.

Сворачиваемые цитаты (FR-UI-01) мешают: в Telegram 13.11, 11:20 ответ агента о доступах был обрезан после 6-й строки — список «Есть (4)» разорван, а главное («Нет: Miro») скрыто в цитате.

## What Changes
- ADDED FR-UI-03: код проставляет в тексте ответа сноски `[1]`, `[2]`, … по списку `links` исполнителя: нумерация сквозная, один URL — один номер, порядок — по первому упоминанию. Нумерованные строки, совпадающие со ссылками 1:1 (бриф, фрагменты playbook), получают свою сноску; иначе сноски ставятся в конце последней строки ответа. Доступы и ответы о людях команды ставят сноску у каждой своей строки, ответ playbook — в конце ответа до пометки о публичном документе; номера, которые пишет LLM playbook, убираются кодом. Готовые сноски (агента `[S#]` → `[n]` и исполнителей) сохраняются; агент видит результаты инструментов без сносок.
- В Telegram HTML каждая сноска — `<a href="URL">[n]</a>`; блока «Источники» нет. Сноска без ссылки удаляется. Простой текст (если Telegram отклонил HTML) — те же сноски и список `[n] URL` в конце, не длиннее 4096 символов.
- REMOVED FR-UI-01: сворачиваемых цитат больше нет. Второстепенные блоки исполнителя (`ExecutorResponse.folded`) идут обычным текстом после основного в прежнем порядке; длинный ответ (в том числе агента) не режется.
- MODIFIED FR-UI-02: код добавляет только `<a href>` сносок и `<b>`; `<blockquote expandable>` не используется.
- Сценарии `live-run-fixes`, где пункты или оглавление показывались «свёрнутым блоком» (FR-H0-14, FR-H3-08), уточнены на «отдельным блоком ниже».

## Impact
`agent/buddy/render.py` (сноски, HTML, простой текст; без цитат и свёртки), `agent/buddy/graph/build.py` (guard), `agent/buddy/rag/qa.py`, `agent/buddy/access/service.py`, `agent/buddy/team/service.py` (сноски у строк), `agent/buddy/agent/loop.py` (наблюдение без сносок), тесты агента. Ссылки по-прежнему только из объектов-источников; `DEMO_MODE=true` и запасные варианты без LLM не меняются. FR-UI-01 живёт в активном изменении `live-run-fixes`: архивировать это изменение после него.
