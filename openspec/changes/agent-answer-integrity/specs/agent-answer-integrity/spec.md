## ADDED Requirements

### Requirement: AI-01 Сохранение источников
Агент SHALL переводить локальные метки результата инструмента в глобальные без потери связи с URL. Допустимые диапазоны SHALL нормализоваться с проверкой границ; неизвестная или повреждённая метка MUST отклоняться.

#### Scenario: Два результата
- **WHEN** второй инструмент возвращает факт с локальной меткой [1]
- **THEN** модели передаётся метка глобального источника этого факта, а не удалённая метка

#### Scenario: Диапазон
- **WHEN** модель возвращает [S1–S3] при трёх источниках
- **THEN** код формирует три ссылки; выходящий за границы или повреждённый диапазон отклоняется

### Requirement: AI-02 Обязательные данные
При выполнении access_status или access_task_analysis агент SHALL сохранять проверенные статусы и источники инструментов кодом, включая сопутствующие части составного ответа. После playbook_qa код MUST сохранять пометку публичности и возможной неактуальности.

#### Scenario: Переписанные доступы
- **WHEN** модель пишет что все доступы выданы, а инструмент сообщает forbidden
- **THEN** итог сохраняет forbidden и соответствующую ссылку из инструмента

#### Scenario: Пересказ playbook
- **WHEN** модель опускает предупреждение об актуальности
- **THEN** код добавляет обязательную пометку в окончательный ответ

### Requirement: AI-03 Свежие данные PR
При ответе о PR без вызова инструмента в текущем ходу агент SHALL дать один повтор с обязательным brief_now в существующем бюджете шагов; неуспех MUST сохранять безопасный fallback. Общий совет SHALL обходиться без персональных инструментов, если пользователь не запросил персональные факты; модель MUST NOT считать найденный PR доказанной причиной затруднений пользователя.

#### Scenario: PR из истории
- **WHEN** модель повторяет факт про PR из истории без инструмента
- **THEN** один повтор требует brief_now, ссылки берутся из текущего результата

#### Scenario: Общий совет
- **WHEN** пользователь просит помочь подготовиться к ревью или справиться с затруднением без запроса персональных данных
- **THEN** агент даёт практический совет без чтения персонального брифа
