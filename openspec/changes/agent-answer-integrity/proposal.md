# Сохранение проверенных фактов в ответе агента

Живой аудит выявил потерю связи фактов со ссылками, переписанные статусы доступа,
пропущенную пометку актуальности H3 и ответ про PR из памяти без свежего источника.
Пользователь поручил исправить найденное и сравнить было/стало, добавив 100 HTTP-попыток.

Сохраняем локальные метки источников при передаче результатов модели; доступы
рендерим из проверенных результатов; предупреждение H3 добавляет код. Неподдержанные
метки отклоняем, допустимые диапазоны нормализуем. Для PR без инструмента даём один
повтор с обязательным brief_now в существующем бюджете шагов. Промпт отличает общий
совет от запроса персональных фактов. Новых прав и корпоративных записей нет.

Критерии eval фиксированы до изменений бота; отчёт сравнивает полный набор с прежним
прогоном и отдельно фиксирует ограничения семантики и изменчивость модели.
