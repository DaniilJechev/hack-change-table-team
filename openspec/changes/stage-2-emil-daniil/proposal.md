# Этап 2: Router, каркас Executors и синтетические данные

## Why
Пользователь поручил выполнить части Эмиля и Даниила отдельно от backend Ильи, продолжая исключительно фикстурную приёмку.

## What Changes
- Router: закрытые 16 кейсов RT-01, промпт/JSON-схема, параметры и правила без LLM.
- Каркас Executors: реестр, схемы, белые списки, максимум 3 вызова, безопасные шаблоны.
- Приватный Telegram-поток /ask, callbacks без Router, /demo next/reset/off и изолированные шаги.
- 70 фраз Router и независимый контрольный набор, карточка команды и каталог доступов.
- Уточнение ошибочного числа 17 в архитектуре/roadmap: источник истины содержит 16 Router-кейсов; brief_render/access_events — отдельные триггеры.

## Impact
Только agent, seed, fixtures, evals, docs, README и OpenSpec. Go backend, REST/buddy-mcp, Compose и CI Ильи не реализуются и не меняются. Бизнес-исполнители H0–H3 следующих этапов остаются шаблонными. Демо явно синтетическое, без внешних аккаунтов.
