## MODIFIED Requirements

### Requirement: FR-H0-08 Статус «прочитан» и метрики
Система SHALL отмечать бриф прочитанным при первом сигнале стажёра — нажатии [✅ Прочитал], открытии остальных пунктов кнопкой «Ещё N», переходе по ссылке через редирект `/r/<token>`, реакции 👍/👎 или ответе на сообщение брифа; `/stats` MUST показывать долю прочитанных брифов и долю брифов с переходами. Для сохранённого в backend брифа при заданном REDIRECT_BASE_URL ссылки MUST использовать выданные backend случайные токены, отдельные от стабильного item_id изменения. В офлайн-демо SeedData, без сохранённого токена или без REDIRECT_BASE_URL ссылка MUST вести прямо на объект.

#### Scenario: Переход по ссылке
- **WHEN** стажёр нажимает [Открыть] у пункта брифа
- **THEN** редирект фиксирует переход, бриф получает read_at, и стажёр попадает на объект

#### Scenario: Нет реакции
- **WHEN** до следующего брифа стажёр не взаимодействовал с текущим
- **THEN** бриф остаётся непрочитанным в метриках

#### Scenario: Ответ на бриф
- **WHEN** стажёр отвечает текстом на сообщение брифа
- **THEN** бриф получает read_at

#### Scenario: Офлайн-демо
- **WHEN** SeedData формирует бриф без backend
- **THEN** ссылки остаются прямыми даже при заданном REDIRECT_BASE_URL, а сигналы кнопок сохраняются в демо-сессии
