# Этап 2: наши данные через buddy-mcp и REST

Поручение Ильи: выполнить его часть Этапа 2 в отдельной ветке от актуального main.
Основа — docs/3_ROADMAP.md, docs/2_ARCHITECTURE.md §5 и действующие H0/H1/H2/platform.

Добавляются шесть инструментов чтения на официальном MCP Go SDK, REST хранения
наших данных и загрузчик существующих синтетических карточки/каталога.
Пользователь и роль определяются сервером на каждом запросе, включая MCP.
Записи доступны только через REST; внешние сервисы не вызываются.

Технические контракты конкретизируются в backend/README.md и backend/openapi.yaml.
Продуктовые требования в openspec/specs и docs не изменяются. Эта дельта остаётся
открытой для командного ревью; архивирование после согласования.
