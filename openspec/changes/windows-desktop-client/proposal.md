# Windows desktop client

## Why

Пользователю нужен Windows-клиент наставника с треем, окном справа и
уведомлениями. Он согласовал общий сервер, Telegram-вход и общую историю.
Текущий бот вызывает AgentService напрямую, HTTP API чата отсутствует.

## What Changes

- Общий канал диалога и пользовательский HTTP API агента.
- Постоянные сессии, история, операции, события и вложения в backend.
- Electron + React клиент, Windows installer и проверки.
- Telegram остаётся каналом того же агента; SSO только обозначен в UI.
- По дополнительному согласованию 14.11 live-ответы desktop копируются в
  привязанный Telegram-чат. Ошибка копирования не отменяет сохранённый ответ;
  повтор одного запроса не повторяет отправку. Desktop-демо изолировано.
- По согласованию пользователя обе стороны отображения/доставки независимо
  управляются галочками; настройки сохраняются в backend, обе включены по умолчанию.

## Impact

Backend, agent, новый desktop-клиент, Compose, CI и инструкция запуска.
Реальные корпоративные интеграции остаются только для чтения.
