# Этап 4 — данные H0/H3 и метрики

## Why
Агент H0/H3 уже в main, но состояние календаря и статистика live-режима теряются
при рестарте, редирект и дашборд ещё не реализованы.

## What Changes
- Постоянные состояние брифов, снимки календаря, настройки и статистика с ролевой изоляцией.
- Согласованные случайные токены редиректов, без произвольного URL в запросе.
- Согласованная интеграция клиента агента, журнала MCP и признака H2/H3.
- Миграция совместимой rag_chunks vector(384), без загрузки модели в BM25.
- Grafana с отдельными Viewer и PostgreSQL ролью только для агрегатов.

## Impact
backend, точечная интеграция agent, Compose, Grafana, техническая документация.
Бот не запускается; проверка на синтетических данных без внешних аккаунтов.
