# Единый формат брифа и продолжения

## Why
Первые пять пунктов переформулируются моделью, а «Ещё N» показывается другим шаблоном с цветными кружками.
Пользователь согласовал единый формат и сохранение кнопки.

## What Changes
Код задаёт номера и источник без цветных кружков, модель меняет только текст.
Проверенные формулировки всех пунктов сохраняются вместе с брифом, включая скрытые.

## Impact
agent/buddy/brief, формат JSON items в существующем REST брифов (необязательное поле render_text).
