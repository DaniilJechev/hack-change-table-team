# PowerPoint MCP в проверке Compose

## Why

infra/smoke.py отклоняет корректный стек с powerpoint-mcp как неизвестный состав.
README описывает PPTX overlay, поэтому такая проверка мешает воспроизводимой приёмке.

## What Changes

- Разрешить присутствующий powerpoint-mcp вместе с пятью обязательными сервисами.
- Проверять его running/healthy, если он присутствует в выводе Compose.
- Сохранить отказ при неизвестном сервисе, отсутствии или нездоровье обязательного.
- Jira/Calendar по-прежнему имеют отдельную проверку MCP; smoke не доказывает чтение PPTX.

## Impact

infra/smoke.py, регрессионные тесты infra/test_smoke.py, README.
Нет изменения продуктовых сценариев или обращения к корпоративным сервисам.
