# Каркас Этапа 0

## Why
В репозитории пока нет исполняемого кода. Илье нужен проверяемый каркас из Этапа 0 дорожной карты, к которому Эмиль сможет подключить свою реализацию агента.

## What Changes
- Добавляются Go-backend с `/health` и Python-заглушка агента с `/health`.
- Добавляются Docker Compose, PostgreSQL 16 с pgvector, Redis 7 и Grafana.
- Добавляются команды запуска, тесты, отчёты покрытия и GitHub Actions.
- Сохраняется полный план части Ильи; сейчас реализуется только его Этап 0.

## Impact
- Новая capability `scaffold`; существующие продуктовые требования не меняются.
- Заглушки не реализуют бота, LLM, MCP, прикладное хранение или сценарии H0–H3.
- Выбор LLM-провайдера и запуск Telegram-бота относятся к Эмилю; инфраструктура лишь передаёт переменные окружения.
