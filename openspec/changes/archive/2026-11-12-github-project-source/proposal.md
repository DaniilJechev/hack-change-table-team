# GitHub проекта как живой источник

## Why
В live-режиме backend отдаёт синтетические логины и каталог без координат GitHub.
Нужно подключить DaniilJechev/hack-change-table-team, сохранив автономное демо.

## What Changes
- Командная live-конфигурация репозитория/объекта каталога и GitHub-логинов через env.
- Персональный бриф (подтверждено Ильёй), проверки участников и ссылка на репозиторий.
- Проверка формата ответов закреплённого MCP, инструкция read-only токена.

## Impact
Backend, Compose, точечная интеграция агента и тесты. Seed/фикстуры остаются синтетическими.
Бот и внешние MCP с настоящими credentials автоматически не запускаются.
