## MODIFIED Requirements

### Requirement: FR-MEM-05 Разрешение уточнений
При включённом агенте подходящие ему уточнения SHALL сначала обрабатываться агентом по истории (FR-AG-11). В режиме Router и при запасном пути агента узел `resolve_followup` SHALL распознавать короткие продолжения («а…», «ещё», «подробнее», «а по Jira?», «второй пункт») правилами без LLM: повторно использовать кейс прошлого хода и заполнять недостающие параметры его сущностями. LLM MAY переформулировать уточнение в самостоятельный вопрос; ответ LLM MUST проходить проверку схемы, а при невалидном ответе, ошибке или таймауте MUST использоваться правила. Без памяти неоднозначное продолжение SHALL обрабатываться Router как прежде. Уточнения по источнику или сущности (номер PR, ключ задачи), относящиеся к брифу, SHALL разрешаться, пока бриф находится в окне памяти, а не только когда он — непосредственно предыдущий ход (FR-H0-12).

#### Scenario: Уточнение по источнику
- **WHEN** прошлый ход — `brief_now` по Git, а пользователь пишет «а по Jira?»
- **THEN** выполняется `brief_now` с источником Jira без вызова LLM

#### Scenario: Невалидная переформулировка
- **WHEN** LLM вернула переформулировку, не прошедшую схему
- **THEN** уточнение разрешается правилами, ответ модели не показывается

#### Scenario: Без памяти
- **WHEN** памяти нет и пользователь пишет «Ну и как?»
- **THEN** Router возвращает `clarify`
