## MODIFIED Requirements

### Requirement: FR-AG-02 Быстрый путь без LLM
Команды (`/…`), кнопки и задачи планировщика SHALL обрабатываться без агента. Уточнения SHALL сначала обрабатываться агентом, если подходят ему; правила FR-MEM-05 применяются в режиме Router и при запасном пути (FR-AG-11). Запрос о зарплате, персональных или медицинских данных MUST получать отказ шаблоном до вызова LLM.

#### Scenario: Команда
- **WHEN** пользователь отправляет `/brief`
- **THEN** бриф собирается без вызова агента

#### Scenario: Персональные данные
- **WHEN** стажёр пишет «Какая у меня будет зарплата?»
- **THEN** бот отвечает шаблоном про HR BP, LLM не вызывается

### Requirement: FR-AG-10 Трассировка запроса
Состояние графа SHALL хранить каждое обращение к LLM за запрос (`llm_calls`: узел, вид `chat`/`complete`, запрос, ответ, ошибка); читаемый вход модели и итог хода SHALL храниться в `turn` по FR-AG-15/16. Запись MUST NOT содержать ключ API. `langgraph dev` SHALL запускать граф на демо-фикстурах с чатом, где состояния узлов и трейсы доступны в LangGraph Studio; в состоянии MUST NOT храниться живой объект `runtime`. Трассировка в LangSmith MUST быть выключена, пока не задан `LANGSMITH_TRACING`.

#### Scenario: Полный промпт в состоянии
- **WHEN** агент ответил на «привет» через LLM
- **THEN** `turn.model_input` содержит раздельные системный промпт, доверенный контекст, историю и текущий вопрос; `llm_calls` содержит запрос со схемами инструментов роли

#### Scenario: Промпт Router
- **WHEN** запрос обработал Router с LLM
- **THEN** `llm_calls` содержит обращение узла `route` с полным текстом промпта

#### Scenario: Следующий ход в том же треде
- **WHEN** в тред Studio приходит второй вопрос
- **THEN** решение, ответ, `llm_calls` и `turn` прошлого хода сброшены, история чата сохранена

#### Scenario: Ключ не попадает в трейс
- **WHEN** LLM вызвана с ключом API
- **THEN** ни `llm_calls`, ни `turn` не содержат ключа
