# Постоянная история H4

## Why
FR-H4-12/14/16 требуют истории после перезапуска, инвалидирования старых кнопок и сохранённых стадий доставки.

## What Changes
Live-история хранится через REST в PostgreSQL с проверкой пользователя. Демо остаётся локальным.
Адрес собственного наставника разрешается служебным REST без выдачи адресов других участников.
