## ADDED Requirements

### Requirement: ST4-GRAPH-1 Детерминированный граф агента
Обработка запроса SHALL выполняться детерминированным `StateGraph` LangGraph с узлами `load_memory → resolve_followup → route → <executor> → guard → save_memory`, где `<executor>` — один узел на семейство кейсов: `brief`, `playbook`, `team`, `access`, `template`. Переход к узлу-исполнителю MUST выбираться кодом по кейсу Router; LLM MUST вызываться только внутри узлов и MUST NOT выбирать рёбра или инструменты вне белого списка кейса. Узел `guard` MUST проверять ссылки и источники и подставлять ссылки кодом. Каждый шаг с LLM MUST сохранять запасной вариант без LLM. Граф MUST работать при `DEMO_MODE=true` на in-memory checkpointer/store без внешних аккаунтов.

#### Scenario: Выбор исполнителя кодом
- **WHEN** Router вернул `team_q2`
- **THEN** выполняется узел `team`, а остальные узлы-исполнители не вызываются

#### Scenario: Прямой триггер в графе
- **WHEN** планировщик запускает `brief_render`
- **THEN** граф передаёт управление узлу `brief` без вызова Router

#### Scenario: Guard отклоняет выдуманную ссылку
- **WHEN** узел-исполнитель вернул ответ со ссылкой на неизвестный `source_id`
- **THEN** узел `guard` заменяет ответ безопасным шаблоном кейса

#### Scenario: Демо без сети
- **WHEN** граф запускается при `DEMO_MODE=true` без внешних аккаунтов и backend
- **THEN** все шаги демо проходят на фикстурах и in-memory хранилище без сетевых вызовов

### Requirement: ST4-GRAPH-2 Флаг движка и паритет
Движок SHALL выбираться переменной окружения `AGENT_ENGINE`: `legacy` (текущий конвейер) или `graph`. При выключенной памяти оба движка MUST давать одинаковые ответы (текст, кнопки, ссылки) на существующем наборе тестов, evals Router и демо-сценарии. Значение по умолчанию MUST становиться `graph` только после прохождения проверки паритета; неизвестное значение MUST приводить к ошибке конфигурации при старте.

#### Scenario: Паритет движков
- **WHEN** набор тестов, evals Router и демо-сценарий прогоняются при `AGENT_ENGINE=legacy` и `AGENT_ENGINE=graph`
- **THEN** ответы обоих движков совпадают по тексту, кнопкам и ссылкам

#### Scenario: Неизвестный движок
- **WHEN** задан `AGENT_ENGINE=react`
- **THEN** агент не стартует и сообщает о недопустимом значении
