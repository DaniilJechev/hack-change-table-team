## ADDED Requirements

### Requirement: FR-H3-07 Уточнения по playbook
Уточняющий вопрос по playbook SHALL переформулироваться с учётом истории в самостоятельный запрос перед поиском (правилами или LLM со схемой и откатом на правила). Запрос «подробнее» MUST использовать фрагменты прошлого ответа по `chunk_id` из памяти без нового поиска. Ответ LLM MUST проходить проверку опоры: если ответ не пересекается по содержанию с найденными фрагментами, бот SHALL показывать только фрагменты со ссылками. Отказ по-прежнему SHALL быть «В playbook этого нет» с кнопкой [Спросить наставника].

#### Scenario: Уточнение с историей
- **WHEN** стажёр спросил «Что такое Zero Bug Policy?», а затем «а кто за неё отвечает?»
- **THEN** поиск выполняется по запросу, включающему Zero Bug Policy, а ответ содержит ссылку на `development-principles.md`

#### Scenario: Подробнее без нового поиска
- **WHEN** после ответа по playbook стажёр пишет «подробнее»
- **THEN** бот отвечает по тем же `chunk_id` из памяти, и поиск по индексу не вызывается

#### Scenario: Ответ без опоры
- **WHEN** LLM вернула ответ, не пересекающийся с найденными фрагментами
- **THEN** бот показывает найденные фрагменты со ссылками вместо ответа LLM

#### Scenario: Уточнение вне корпуса
- **WHEN** после ответа по playbook стажёр спрашивает «а пароль от Wi-Fi?»
- **THEN** бот отвечает «В playbook этого нет» с кнопкой [Спросить наставника]
