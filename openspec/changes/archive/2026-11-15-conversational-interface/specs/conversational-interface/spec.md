## ADDED Requirements

### Requirement: FR-CONV-01 Основной диалог
Приветствие, основная помощь и подсказки демо SHALL предлагать обычный текст вместо /ask. Команда /ask MUST сохранять прежнее меню для совместимости.

#### Scenario: Подсказки и совместимость
- **WHEN** пользователь открывает помощь или демо
- **THEN** /ask не рекламируется, но явная команда /ask открывает восемь типов вопросов

### Requirement: FR-CONV-02 Естественное уточнение
Работающий агент с LLM SHALL задавать один конкретный уточняющий вопрос при недостаточной ясности, без меню классификации. При сбое LLM MUST сохраняться детерминированный запасной путь. Проверенные брифы, статусы доступов, H4, источники и кнопки MUST сохраняться.

#### Scenario: Агент уточняет
- **WHEN** LLM отвечает уточняющим вопросом без инструментов
- **THEN** бот показывает вопрос без восьми кнопок

#### Scenario: Сбой модели
- **WHEN** LLM недоступна
- **THEN** обработка продолжается через Router и безопасные шаблоны

### Requirement: FR-CONV-03 Справка по командам
Agent и Router MUST получать общую справку по назначению команд. Вопрос о команде SHALL объясняться без чтения корпоративных данных и без исполнения команды; при сбое модели SHALL использоваться точная программная справка. Личные текущие настройки MUST NOT выдумываться.

#### Scenario: Объяснение settings
- **WHEN** пользователь спрашивает «что делает /settings?»
- **THEN** ответ объясняет время брифа и quiet, не меняя настройки и не вызывая продуктовые инструменты

#### Scenario: Settings при сбое
- **WHEN** модель недоступна при вопросе о /settings
- **THEN** ответ содержит /settings brief HH:MM и /settings quiet on|off

#### Scenario: Прямая команда
- **WHEN** пользователь отправляет /settings quiet on
- **THEN** сохраняется прежняя программная обработка команды
