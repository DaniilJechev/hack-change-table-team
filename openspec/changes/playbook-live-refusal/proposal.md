# Свежий поиск playbook вместо отказа из истории

В живом диалоге повторный вопрос о ценностях получал выдуманный отказ без поиска.
Вводное «поищи что-то про» также ошибочно блокировало ответ через unknown-word gate.
Пользователь поручил исправить оба дефекта и обновить работающего бота.

Нормализуем только вводные поисковые просьбы. Содержательные неизвестные слова
и пороги остаются. Для H3-вопросов, определяемых существующими правилами, требуем
текущий playbook_qa; при нарушении моделью требования выполняем его кодом.
Одиночный H3-результат сохраняется без повторного пересказа внешним агентом.
Тесты воспроизводят ложный отказ из истории, вводные и настоящий отказ вне корпуса.
