# Кликабельные сноски в AvitoCode

## Why
AvitoCode показывает `[n]` обычным текстом и требует раскрывать список источников.
Пользователь запросил открытие источника нажатием на номер, как в Telegram.

## What Changes
- Сноски ответа и дополнительных блоков становятся ссылками из `response.links`.
- При отсутствии сносок используется расстановка как в Telegram.
- Отдельный список источников заменяется сносками в тексте.
- Markdown-ссылки и код сохраняются; произвольный HTML не исполняется.

## Impact
Только рендер desktop; API, агент и реальные сервисы не меняются.
