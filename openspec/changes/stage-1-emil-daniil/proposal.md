# Этап 1: задачи Эмиля и Даниила

## Why
Каркас main не имеет MCP-клиентов и набора воспроизводимых данных для сценария «день стажёра».

## What Changes
- MCP Python SDK: stdio/Streamable HTTP, discovery, проверка имён и схем, белые списки чтения.
- Запись и воспроизведение ответов; CLI для проверки четырёх серверов и OAuth Miro.
- Синтетический набор данных, план подготовки реальных тестовых объектов и отчёт о происхождении roadmap.

## Impact
Только agent, seed/fixtures, вспомогательные сценарии, OpenSpec и отчёт. Backend, Compose, инфраструктура и Router/Executors не реализуются и не меняются. Поднятие серверов — зависимость от Ильи. Без аккаунтов живые проверки отмечаются как невыполненные, а не подменяются фикстурами.
