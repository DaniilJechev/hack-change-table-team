# Автоматические релизы AvitoCode

## Why
Пользователь согласовал публикацию Windows-установщика в GitHub Releases,
чтобы скачивать EXE со страницы версии, а не искать ZIP в артефактах CI.

## What Changes
- Запуск существующего CI по тегам `vMAJOR.MINOR.PATCH`.
- Проверка совпадения тега с версией desktop и принадлежности коммита main.
- Публикация релиза с EXE и SHA256SUMS после всех проверок.
- Инструкция выпуска; опубликованные версии не перезаписываются.

## Impact
GitHub Actions, проверка версии desktop и инструкция. Автообновление приложения
и цифровая подпись установщика не добавляются. Первый тег автоматически не создаётся.
