# AvitoCode: согласованный план Windows-клиента

Основа: `main` после pull, `6c53235`; ветка `feat/desktop-windows-client`.

Согласовано пользователем: Electron + React/TypeScript; Windows 10/11 x64;
общий сервер с настраиваемым HTTPS-адресом (в том числе ngrok); вход через
подтверждение Telegram; кнопка SSO показывает «В разработке». Общие профиль,
память и личная переписка; ответ в канал обращения и копия live-ответа desktop
в Telegram, фоновые события в оба. Копирование desktop-ответов согласовано
дополнительно 14.11; синтетическое desktop-демо остаётся изолированным.
Обе стороны управляются независимыми галочками в desktop: показывать Telegram
и отправлять desktop-ответы в Telegram. Обе по умолчанию включены; настройки
сохраняются в backend. Скрытие не удаляет историю и не влияет на брифы.
Все H0–H4, оценки, источники, вложения и действия наставника.

Каждый запуск скрыт в трей; автозапуск включается пользователем. Окно справа
занимает около трети рабочей области, поверх обычных окон, resizable;
крестик, сворачивание и Escape скрывают. Мониторы/DPI/размеры учитываются.
Уведомления с фрагментом ответа только вне активного чата; клик открывает
нужное сообщение. История восстанавливается без повторных уведомлений.

## Границы

Клиент не запускает backend и не содержит ключей сервисов/LLM.
SSO — только заглушка. Старые сообщения Telegram не импортируются.
Одна личная история на пользователя/команду. Незавершённые операции при
перезапуске отмечаются прерванными без автоматического повторения записей.
Настоящий бот/публикация/деплой не запускаются автоматически.
Первая сборка для пилота без подписи и автообновлений; Windows-приёмка
обязательна отдельно от Linux/CI. Плановая оценка: 12–18 рабочих дней.
