## Найденное замечание [P1] — исправлено в интеграции

В backend/internal/store/team_card.go таблица cardSchema не разрешала поле stage. Карточка Этапа 3 содержит stage.epic_key и source_url: без них H2 Q5 не определит эпик. Поэтому штатная карточка агента получала 400 при загрузке.

Воспроизведение: в отдельном checkout исходного PR заменена только seed/team_cards/demo-orders.yaml фактической карточкой Этапа 3; запуск существующего TestFR_H2_01_CardSchemaAndFieldPaths завершился FAIL со значением [{* неизвестное поле}]. Основной репозиторий Ильи при этом не изменялся.

Исправление: сохранён backend Ильи; stage добавлен как опциональный типизированный объект с epic_key/source_url. Неизвестные вложенные поля, неверный URL и пустой epic_key отклоняются. Добавлен TestST3_CARD_2_StageMetadataValidation. Полный совместный Go-прогон с новой карточкой и PostgreSQL прошёл, покрытие 92.3%, go vet успешно. Откатывать H2 или удалять metadata из карточки не потребовалось.
