## Что изменено

1. `_observe` переводит локальные ссылки инструмента в глобальные метки, сохраняя
   соответствие «факт → источник». Раньше код удалял метки из текста, а модели
   оставалось угадывать соответствие по отдельному списку URL. Учтены дубликаты URL.
2. Код нормализует группы и диапазоны `[S1–S3]`, проверяет границы, отклоняет
   повреждённые метки. Окончательные номера и URL по-прежнему создаёт код.
3. При наличии результата по доступам составной ответ собирается из результатов
   Executors: модель больше не заменяет forbidden на granted, не теряет статусы
   и не переставляет их источники. Сохраняются сопутствующие части, действия и сущности.
4. После `playbook_qa` код обеспечивает обязательную пометку публичности и возможной
   неактуальности. Модель не может убрать её пересказом.
5. Для ответа о PR без свежего инструмента добавлен один повтор с обязательным
   `brief_now` в пределах прежнего бюджета шагов, затем остаётся безопасный fallback.
6. В промпте уточнены общие советы о ревью и блокерах, запрет приписывать причину
   затруднения конкретному PR без слов пользователя, избыточность access_status
   при access_task_analysis. Никакие новые инструменты записи не добавлены.
