## Реализация

- `/r/{token}`: отдельный 256-битный случайный токен пункта/доставки, URL только из БД,
  sent-only, идемпотентный click и неизменное первое read_at. HEAD не считается чтением;
  no-store/no-referrer. Стабильный ID изменения остаётся для дедупликации.
- Атомарное подтверждение доставки со снимком календаря, предыдущая база не теряется
  при failed/ошибке источника/повторном подтверждении старого брифа.
- Постоянные last_sent, seen, настройки времени/quiet и статистика с правами:
  стажёр — себя, наставник — своих стажёров, тимлид — стажёров команды.
- BackendData подключён к REST; кнопки сохранённого брифа восстанавливаются по ID.
  Офлайн SeedData сохраняет автономность и прямые ссылки без неработающих токенов.
- Необязательные валидируемые target в каталоге для внешних ID объектов H0/H1;
  без credentials, с атомарным отказом seed на неизвестных полях.
- Категории вопросов h2/h3, неизменные при повторах. Исторические записи — unknown.
  Оценки ответа бота и человека считаются раздельно, по последнему значению.
- Постоянный журнал MCP без аргументов/ответов. Hub сохраняет разрешённые вызовы,
  ошибки и отдельные tool_denied; свой SDK — buddy_read. Отмена — cancelled.
- Миграция rag_chunks vector(384) совместима с e5-small и прежним индексом.
  Индексация пишет данные, схему создаёт backend. BM25 не загружает модель.
- Grafana: дашборд H0–H3, PostgreSQL datasource с отдельным buddy_metrics,
  SELECT только агрегатных views без исходных таблиц, Viewer для просмотра.
  Подготовка Viewer включена в make up/demo, повторная команда — make grafana-setup.
- `make stage4-check` включён в CI Compose после seed/buddy-check.
  Контракты и ограничения описаны в backend/README.md и backend/openapi.yaml.

## Границы приёмки

Это локальная приёмка backend-части на синтетических данных. Удалённый CI до публикации
ветки не запускался. Реальные аккаунты, настоящая LLM, доставка сообщений Telegram,
запись видео и сбор опроса этим поручением не выполнялись.

REDIRECT_BASE_URL должен быть доступен устройству пользователя; сетевой деплой/HTTPS
не входят в работу. Демо SeedData и его статистика сессионные и не наполняют Grafana.
Соответствие Telegram message_id → brief_id и активные чаты планировщика ещё в памяти
агента; сохранение текстовых ответов на старые сообщения после рестарта не гарантировано.
При сбое БД аудит сохраняется без гарантированной очереди: предупреждение не ломает
ответ пользователю. GET-превью ссылки может считаться кликом; это не доказательство
прочтения человеком. Дашборд считает показатели за всё время, а не результаты пилота.
