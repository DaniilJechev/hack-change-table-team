# Задача: guard вставляет ссылки-сноски [1], [2], … в формате Telegram

**Что сделать:** в guard-узле агента (`agent/buddy/graph/build.py`, и `agent/buddy/rag/qa.py`, если там своя проверка ссылок) сделать так, чтобы ссылки на источники вставлялись как нумерованные сноски `[1]`, `[2]`, … в формате Telegram, а не голым URL.

## Требования

1. Guard (код, не LLM — правило 2 в AGENTS.md) берёт список источников, собранных из результатов инструментов/RAG, и проставляет в тексте ответа маркеры `[1]`, `[2]`, … рядом с фактом, который они подтверждают.
2. Каждый маркер — кликабельная ссылка в Telegram HTML: `<a href="URL">[1]</a>`. Ссылку берём только из реального объекта-источника (никаких URL, придуманных LLM).
3. Отдельного блока «Источники» в конце ответа **нет**. Маркер ставится сразу в конце того пункта (строки/абзаца), где использована информация из источника: `Ревью PR по авторизации [1]` → `Ревью PR по авторизации <a href="URL">[1]</a>`. Если в пункте несколько источников — несколько маркеров подряд: `<a href="URL1">[1]</a> <a href="URL2">[2]</a>`.
4. Нумерация сквозная по всему сообщению, без дублей: один и тот же URL получает один и тот же номер. Порядок — по первому упоминанию.
5. Если у факта нет источника — guard не выдумывает ссылку (как сейчас: пункт скрывается либо помечается по действующей спецификации).
6. Экранировать HTML-спецсимволы (`<`, `>`, `&`, `"`) в тексте и в атрибуте `href`; parse_mode бота — `HTML`. Учесть лимит Telegram 4096 символов (сноски не должны ломать разбиение сообщения).
7. Запасной вариант без LLM сохраняется; демо-режим (`DEMO_MODE=true`) на фикстурах не ломается.

## Процесс (по AGENTS.md)

- Сначала проверить `openspec/specs/*/spec.md` (требования `FR-H0-LINK-*` и связанные про ссылки) и `openspec/changes/agent-orchestrator/`; если поведение меняется — обновить дельту в `changes/`, затем код.
- Тесты в именовании `test_fr_..._`, минимум по одному на сценарий: вставка маркеров, дедупликация URL, ответ без источников, экранирование HTML, длинный ответ. LLM — фейк.
- Прогнать `pytest` для `agent`, покрытие > 80 %.
- Обновить кейсы в `evals/agent/cases.jsonl`, если проверяется формат ссылок.

## Критерий готовности

В ответе бота `[1]`, `[2]` кликабельны в Telegram и стоят сразу в пунктах, где использована информация; списка источников в конце нет; все URL — из реальных источников; тесты зелёные.
