## Диагностика Electron после двух повторов npm run dev

Пользователь разрешил диагностику за пределами README. В чистой копии отсутствуют
`desktop/node_modules/electron/path.txt` и `dist/electron.exe`. Пакет electron 45.3.2
установлен, но в его package.json нет postinstall, загружающего бинарник.
electron-vite 6.0.0 проверяет path.txt до запуска Electron и бросает `Electron uninstall`.
Поэтому повтор `npm ci` или `npm run dev` сам по себе проблему не устраняет.

Официальная документация Electron описывает загрузку бинарника при первом прямом
запуске Electron и отдельную команду `npx install-electron --no`:
https://www.electronjs.org/docs/latest/tutorial/installation#binary-download-step

Штатный `node node_modules/electron/install.js` был запущен отдельно. Его временный
ZIP оставался нулевым; установщик остановлен. Причина сетевого зависания Node не установлена.
Через curl официальный URL возвращает HTTP 200 и передаёт данные. Первая загрузка
достигла 30 523 097 из 158 318 730 байт за 120 секунд; продолжена с места обрыва.
Перед распаковкой требуется совпадение SHA256 с checksums.json установленного пакета.
Этот обход не считается успешным выполнением исходной инструкции README.

### Результат диагностики

Официальный ZIP полностью загружен; SHA256 совпал с checksums.json пакета.
Архив распакован в node_modules/electron/dist, path.txt содержит electron.exe.
Повтор `npm run dev` прошёл прежнюю ошибку и вывел `starting electron app...`;
процесс остаётся запущен. Далее клиент сообщил HTTP 404 — подключение к чистому
серверу через настройки ещё предстоит проверить. Возможное наследование пользовательских
настроек desktop на этом хосте не позволяет считать эту проверку новой Windows-системой.

В основной README и desktop/README добавлена официальная команда установки бинарника
`npx install-electron --no` после npm ci. Чистый снимок оставлен с исходной инструкцией,
чтобы не подменять историю первого прогона. Прямое скачивание curl — диагностический
обход сетевого зависания; успешная загрузка через штатный Node-установщик пока не подтверждена.
