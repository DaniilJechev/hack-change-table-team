# Сценарий видео (Этап 4, черновик Даниила)

Длительность — около 3 минут. Запись идёт в демо-режиме (`DEMO_MODE=true`): синтетическая команда
«Учебная команда заказов», стажёр Даниил, наставник Анна, тимлид Олег, инженер Пётр. Внешние
аккаунты и LLM не нужны. Точные ответы бота для каждого шага — в `STAGE_4_DEMO_TRANSCRIPT.md`.

Перед записью: `/demo reset`. Каждая строка таблицы — один кадр.

## Замечания к записи

- Кадр 3: в демо без LLM строки брифа — шаблонные. Если к записи подключим LLM, формулировки станут
  другими, а порядок пунктов и ссылки останутся теми же.
- Кадр 10: в режиме `bm25` (без модели) бот показывает найденный фрагмент целиком; связный ответ в
  2–5 предложений появляется только с LLM. Для видео решить заранее, какой вариант показываем.
- Кадр 12: статистика брифов в демо показывает «с переходами 0 %» — учёт переходов появится с
  редиректом `/r/<item_id>` (часть Ильи).
- Бот сейчас выключен по решению Даниила; для записи его нужно включить отдельно.
