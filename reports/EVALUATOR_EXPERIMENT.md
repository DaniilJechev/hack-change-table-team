## Ограничения и следующий этап

Критерии на фрагментах и regex могут пропустить отрицание, неверную связь фактов или правильные
слова в бессмысленном ответе. Наличие ожидаемого URL не доказывает подтверждение каждого факта.
Языковые проверки эвристические и имеют ложные срабатывания/пропуски. Завершение Registry не
равно успеху каждого вложенного MCP-вызова. Fallback по умолчанию запрещён как отдельная метрика
качества агента; успешность запасного сценария ещё нужно оценивать отдельным набором.

Следом: успешный ограниченный LLM-прогон в среде с доступом к API → ручная проверка ложных
провалов критериев → полные H0/H1/H4 со сменой состояния → независимые формулировки и повторы →
калибровка семантического судьи на ручной разметке. Экономия времени наставника — отдельный
пользовательский эксперимент. Не подгонять критерии ради роста процента без проверки источников.

Для продолжения общего бюджета этой работы осталось не более **131 HTTP-попытки**.


## Диагностика и повтор 14.11

DNS openrouter.ai разрешается, но исходящий TCP на порт 443 отклоняется Windows с ошибкой
сокета 10013 (WSAEACCES: доступ запрещён). Это ограничение процесса/среды до HTTP и TLS,
а не ответ провайдера. Точный компонент, установивший запрет (sandbox/firewall), не установлен.
Проверка без ключа и прямой TCP-тест воспроизводят проблему; локальный сервис бота на неё не влияет.

CodexSandboxService.OpenAI.Codex уже Running; com.docker.service Stopped. Попытка Start-Service
отклонена правами. Эти evals выполняют Agent/Registry прямо в Python на фикстурах, поэтому
не требуют Docker, backend или запущенного Telegram-бота.

Повтор реальной LLM ограничен одной HTTP-попыткой: evals/agent/experiment-retry.json.
ConnectError подтверждён, HTTP-ответов 0. Всего 70 из 200 попыток, осталось не более 130.
Полный прогон не повторялся: сетевое условие не изменилось. После восстановления доступа:


которому разрешены исходящие соединения. Лимит 130 сохраняет общий бюджет этой работы.
