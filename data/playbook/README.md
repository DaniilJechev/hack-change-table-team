# Снимок AvitoTech Playbook

- Источник: https://github.com/avito-tech/playbook (публичный репозиторий Авито).
- Коммит: `0c1d2aa1501ca6889357908f54b12695f0534e48`.
- Состав: 28 markdown-файлов из корня репозитория в `snapshot/`, без картинок и служебных файлов.
- Назначение: корпус для H3 (ответы бота со ссылкой на файл и раздел на GitHub).

Тексты принадлежат их авторам и Авито; в исходном репозитории нет файла лицензии, поэтому снимок
используется только как корпус учебного проекта хакатона и не изменяется. Playbook может быть
устаревшим — бот добавляет эту пометку к каждому ответу.

Индекс строится командой `make ingest` и сохраняется в `agent/buddy/rag/data/index.json`
(622 фрагмента по заголовкам). Чтобы обновить снимок, замените файлы в `snapshot/`, поменяйте
`COMMIT` в `agent/buddy/rag/ingest.py` и запустите `make ingest`.
