# Оценки AI-buddy

Все текущие отчёты получены без сети и без реальной LLM, на синтетических данных.

```sh
uv run --project agent --frozen --extra dev python evals/run_router.py
uv run --project agent --frozen --extra dev python evals/run_router.py --dataset evals/router/holdout.jsonl
uv run --project agent --frozen --extra dev python evals/run_h2.py
uv run --project agent --frozen --extra dev python evals/run_h3.py
```

- Router: 70 основных + 16 контрольных фраз; все кейсы и параметры совпадают. Контрольные наборы использованы при разработке и не являются слепым holdout.
- H2: 40 вопросов, Q1–Q8 по 5. Отдельно считаются выбор кейса, ожидаемый факт и наличие ссылки; 40/40 по каждой проверке. Ожидаемые формулировки q4/q8 обновлены после исправления грамматики и названий сервисов, сами ожидаемые факты сохранены.
- H3: 35 вопросов (30 по корпусу, 5 вне корпуса), снимок playbook на коммите 0c1d2aa, 622 фрагмента.
  Считаются: выбор кейса Router, файл-источник в топ-1 и топ-3, ложные отказы, отказ на вопросы вне корпуса.
  Текст ответа и LLM не оцениваются.

  | Режим (`RAG_SEARCH_MODE`) | Топ-1 | Топ-3 | Ложные отказы | Отказ вне корпуса | Что нужно |
  |---|---|---|---|---|---|
  | `bm25` (по умолчанию) | 28/30 | 29/30 | 1 | 4/5 | ничего: без модели, без БД, без сети |
  | `vector` | 29/30 | 30/30 | 0 | 3/5 | набор `rag`, pgvector, `make ingest` |
  | `rrf` | 30/30 | 30/30 | 0 | 3/5 | то же |

  Отчёты `vector` и `rrf` сняты локально 11.11 с `intfloat/multilingual-e5-small` и временным
  pgvector; в CI воспроизводится только `bm25`. Порог близости 0,82 подобран на этом же наборе
  (вопросы по корпусу дают 0,82–0,94, вне корпуса — 0,78–0,85), поэтому цифры отказа оптимистичны.
  Два неотсечённых вопроса вне корпуса — про отпуск стажёра и про зарплату; второй до H3 не доходит:
  Router отправляет его в `out_of_scope`.

  ```sh
  uv run --project agent --frozen --extra dev python evals/run_h3.py              # bm25
  uv run --project agent --frozen --extra dev --extra rag python evals/run_h3.py --mode rrf
  ```
- pytest воспроизводит закоммиченные JSON-отчёты.

Это не результаты настоящей модели и не пользовательского пилота. Реальный Router-eval возможен только явным --mode llm при локально настроенных LLM_*; в этой работе не запускался.

## Агент (FR-AG-07)

`evals/agent/cases.jsonl` — 34 кейса: выбор инструмента, составные и открытые вопросы, вопросы без
данных, инъекции, уточнения, роль наставника и быстрый путь без LLM. Инструменты работают на демо-фикстурах,
настоящая только LLM. Скрипт считает по каждой модели: верный набор инструментов, ответы агента без
запасного варианта, заблокированные кодом ответы без опоры (FR-AG-09), причины запасного варианта,
среднюю и p95 задержку, стоимость OpenRouter. Прогон тратит деньги и запускается вручную; отчёт — `evals/agent/report.json`.

```sh
uv run --project agent --frozen python evals/run_agent.py \
    --models deepseek/deepseek-v4.1-flash-1017 anthropic/claude-haiku-5.5
```

Прогон 12.11 (демо-фикстуры, 34 кейса, `evals/agent/report.json`):

| Модель | Верные инструменты | Ответ агента без запасного | Заблокировано кодом | p95 | Стоимость |
|---|---|---|---|---|---|
| `deepseek/deepseek-v4.1-flash-1017` | 34/34 | 28 | 2 (`label`) | 6,1 с | $0.0078 |
| `anthropic/claude-haiku-5.5` | 34/34 | 27 | 3 (`task`, `answer`, `label`) | 4,7 с | $0.0156 |

«Ответ агента» не включает 4 кейса быстрого пути без LLM. Все заблокированные ответы получили запасной
вариант (результат инструмента или Router). Набор маленький и составлен разработчиком — это не слепая оценка.
