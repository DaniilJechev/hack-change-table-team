# Метрики бота и эффект для наставника

Актуализировано 15.11.2026: по решению пользователя расширение каталога метрик
отменено. Сохраняются только пять существующих SQL-агрегатов и панели Grafana.
Главная цель продукта — сократить рутинные часы наставника на стажёра.

## 1. Что именно измеряем

- Бот наблюдает обращения внутри своих каналов, результаты операций и явные реакции.
- Время наставника и обращения в личку вне бота напрямую не наблюдаются.
- Полезный ответ, клик, отсутствие эскалации и подтверждённое решение — разные сигналы.
- Ход диалога не равен отдельному вопросу: уточнения и повторы могут относиться к одной проблеме.
- Отсутствие события может означать отказ записи; TraceSink не блокирует ответ при сбое backend.

Фактическая экономия времени наставника не измерена. Из количества сообщений,
кликов и оценок полезности её вычислять нельзя.

## 2. Уже существующие агрегаты

SQL-источники: [00005_stage_four.sql](../backend/migrations/00005_stage_four.sql),
[00007_agent_traces.sql](../backend/migrations/00007_agent_traces.sql).
Панели: [ai-buddy.json](../infra/grafana/dashboards/ai-buddy.json).

| Агрегат | Что есть сейчас | Ограничение |
|---|---|---|
| `metrics_briefs` | Отправленные, прочитанные, с кликом; read_percent/clicked_percent | Sent-брифы пользователей intern; общий срез без временного разреза |
| `metrics_helpful` | Число оценок, положительных оценок, их доля; H2/H3, bot/human | Доля только среди оценённых; не подтверждает решение |
| `metrics_access` | Завершённые запросы и среднее время от отметки до снимка granted | Наблюдаемое время обнаружения; не время работы наставника; зависит от частоты опроса |
| `metrics_mcp` | Число вызовов по сценарию/серверу/инструменту/исходу | Отказ политики не обязательно ошибка продукта; нет стоимости человеческой работы |
| `metrics_agent` | Ходы по UTC-дню/пути, fallback %, avg/p95 latency, avg tool_calls | Сейчас смешивает demo/live и роли; путь и case не описывают весь составной вопрос |

Grafana получает только разрешённые агрегаты. Доступ к raw-трейсам, текстам и таблицам
пользователей ей не выдаётся.

## 3. Решение об отмене расширения

Дополнительные показатели BOT-01…10 и OUT-01…06, новые события исходов вопросов,
связи проблем и версий, расчёт предотвращённых часов и новый дашборд отменены.
Они не входят в текущий объём работ и не являются задачами следующей итерации.
Их реализация не начиналась: новые миграции, события и панели не добавлялись,
откат кода и схемы БД не требуется.

Существующие трейсы, история H4, оценки и доставка продолжают работать по
спецификациям. Их наличие не означает наличие новых продуктовых метрик.

## 4. Ограничения текущих данных

- Текущий metrics_agent объединяет demo/live и роли, а день считает по UTC.
- Ошибка записи трейса не блокирует ответ; часть событий может отсутствовать.
- Прямые команды, H4 и интерактивные пути покрыты трассами не полностью.
- Срок хранения трейсов по умолчанию — 30 дней; истории H4 — 7 дней.
- Взаимодействия вне бота и фактические трудозатраты наставника не наблюдаются.

Исходная цель снижения рутины наставника не менее чем на 25% остаётся продуктовой
гипотезой. Пользовательский пилот не проведён; достигнутая экономия не заявляется.
